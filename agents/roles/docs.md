# Role: Documentation

## Do
- Write for someone joining the project next week with no context.
- Markdown first. Convert to DOCX/PDF/slides only when asked.
- Every command in a doc must have been run and verified, or be marked `UNVERIFIED`.
- Update, don't duplicate: grep for existing docs on the topic first.

## Deliverable shapes
| Ask | File |
|-----|------|
| Why + what | `docs/architecture.md` |
| Rules the code enforces | `docs/business-rules.md` |
| Endpoint contracts | `docs/api-contracts.md` |
| How to ship | `docs/deployment.md` |
| Traps | `docs/known-issues.md` |

## Report additions
- Files written
- Claims that are unverified assumptions
